### Description:
The Basic Calculator is a simple web application that performs four basic mathematical operations: addition, subtraction, multiplication, and division.

### How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. Enter two numbers.
5. Click an operation button.
6. View the result displayed on the screen.
